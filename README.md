📋 HƯỚNG DẪN CHẠY WEB TRÊN MÁY TÍNH KHÁC 1️⃣ Yêu cầu trên máy tính mới: Đã cài Python 3.10 trở lên (khi cài nhớ tích chọn "Add Python to PATH"). Trình duyệt web (Chrome hoặc Edge). 2️⃣ Các bước thực hiện trên máy mới (Chỉ mất 2 phút): Bước 1: Copy thư mục dự án Copy toàn bộ thư mục ADCP sang máy mới (ví dụ lưu tại ổ D:\ADCP). Bước 2: Mở PowerShell / Command Prompt tại thư mục dự án Mở PowerShell và gõ: powershell cd D:\ADCP Bước 3: Tạo & Kích hoạt Môi trường ảo (Venv) powershell # Tạo venv python -m venv venv # Kích hoạt venv trên Windows .\venv\Scripts\activate (Thấy hiện chữ (venv) ở đầu dòng lệnh là thành công) Bước 4: Cài đặt thư viện AI & Web Server (1 câu lệnh duy nhất) powershell pip install fastapi uvicorn sqlalchemy aiosqlite opencv-python mediapipe ultralytics torch torchvision Bước 5: Tạo dữ liệu 4 sinh viên (Phát, Đạt, Minh, Long) powershell python seed_team.py Bước 6: Khởi chạy máy chủ Web AI Server powershell uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload 🌐 3️⃣ Mở trang Web để sử dụng: Chạy trên máy tính đó: Mở Chrome/Edge và truy cập: 👉 http://127.0.0.1:8000/ui/index.html Truy cập từ Điện thoại / Laptop khác trong cùng mạng Wi-Fi: Mở CMD gõ ipconfig để xem IP của máy (ví dụ 192.168.1.15). Trên máy khác hoặc điện thoại gõ: 👉 http://192.168.1.15:8000/ui/index.html
